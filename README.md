# ⚡ VocabMaster - 忘却曲線英単語フラッシュカードアプリ

ブラウザ・スマートフォン両対応のモダンな英単語学習PWAアプリケーションです。
外部サーバーやデータベース契約不要で、ブラウザ内ストレージ（IndexedDB）に完全保存されます。

## 🌟 主な特徴
1. **科学的忘却曲線（SM-2アルゴリズム）**
   - 世界的人気アプリ「Anki」等と同様のアルゴリズムを採用。
   - 復習時の自己評価（もう一度・難しい・普通・簡単）に応じて、最適な次回復習日を自動スケジューリング。
2. **CSV / TSV 一括インポート**
   - ExcelやGoogleスプレッドシートからドラッグ＆ドロップで一瞬で取り込み可能。
   - 列名（word, meaning等）を自動判定。2列（単語, 意味）だけでもOK。
3. **ネイティブ発音再生**
   - Web Speech APIにより、追加料金ゼロで英語の発音をクリアに読み上げ。
4. **スマートフォン対応（PWA）**
   - スマホのブラウザで開き「ホーム画面に追加」するだけで、アプリのように全画面・オフラインで動作。
5. **PCキーボードショートカット対応**
   - `Space` / `Enter`: カードを裏返す
   - `1`: もう一度（Again）
   - `2`: 難しい（Hard）
   - `3`: 普通（Good）
   - `4`: 簡単（Easy）

## 🚀 起動方法
1. このフォルダ内の **`start_app.bat` をダブルクリック** してください。
2. 自動的にブラウザが立ち上がり、アプリが起動します。

## 📱 スマートフォンで使う方法（同一Wi-Fi）
1. PC側で `start_app.bat` を起動したままにします。
2. PCのIPアドレス（例: `http://192.168.1.X:8080`）をスマホのブラウザ（SafariやChrome）で開きます。
3. ブラウザメニューの「ホーム画面に追加」をタップすると、アプリとしてインストールできます。
